{{ _('Remplir la boîte avec le câble USB-C') }}

{{ _('Associer un tag') }}

{{ _("Dans la Bibliothèque, touchez la pastille « Sans tag » d'une histoire ou d'un album, puis posez le tag sur la boîte. Pour retirer un tag, touchez la pastille « Tag associé ». La page « Tags » montre tous les tags déjà associés.") }}

{{ _("Dans « Tags », vous pouvez donner un nom à chaque tag (« Loup bleu ») pour le reconnaître. Dans la Bibliothèque, le filtre « Sans tag » regroupe les histoires et les albums qui n'en ont pas encore.") }}

{{ _("Ce que fait l'enfant") }}

{{ _("Il pose un tag : son contenu joue, tant que le tag reste posé. Il le retire : la lecture s'arrête en douceur et la boîte retient où il en était. Il le repose aussitôt (dans les 3 secondes) : l'histoire repart du début, un petit son le confirme.") }}

{{ _("Un tag peut jouer une histoire, un album entier ou une liste de lecture. Dans « Tags », choisissez pour chacun s'il reprend où il en était ou repart toujours du début, s'il mélange l'ordre et s'il recommence à la fin.") }}

{{ _("Voyant vert : la boîte est allumée (il clignote vite quand elle est reliée à un ordinateur, lentement en veille). Voyant rouge : une lecture est en cours.") }}

{{ _("Ouvrez la fiche d'un livre ou d'un morceau pour voir ses informations, puis touchez « Lire ». La page « Lecture » permet ensuite de mettre en pause, d'avancer ou de reculer, et de régler le volume.") }}
